# Linux & Network Security Lab

A hands-on cybersecurity laboratory by Dhio35.

## Objectives

- Linux system administration
- User and permission management
- SSH security and hardening
- Linux firewall configuration
- Network analysis and troubleshooting
- Python security automation

## Environment

- Windows 11
- WSL2
- Ubuntu 26.04 LTS
- Python 3.14
- Git

## Project Structure

- docs/: Technical documentation
- labs/: Practical security exercises
- scripts/: Automation scripts
- evidence/: Lab screenshots and evidence

## Learning Approach

Each laboratory contains:
1. Objective
2. Technical concepts
3. Implementation
4. Testing
5. Findings
